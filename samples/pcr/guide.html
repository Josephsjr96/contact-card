VESPER / DNA INPUT & MODEL SCOPE

Real sequence input.
Simulated laboratory signals.

VESPER can load a DNA sequence from a public reference or a real sample that has already been sequenced. It searches that sequence for a supplied primer pair and generates an educational PCR/qPCR simulation. It runs entirely in your browser.

How to import your sequence

  1. Choose Import DNA FASTA in the specimen archive.
  2. Paste DNA text or select a supported file. Enter a specimen name and your forward and reverse primers, both in 5′→3′ orientation.
  3. Set expected starting copies and add the sequence to the archive. Clear the tray before switching to an assay with a different primer pair.
  4. Select the imported vial, load it into a tray slot, configure the protocol and start amplification. Inspect the predicted product, generated curves, controls and Results & QC.
Sequence formatsOne FASTA record or plain DNA text. File extensions: .fasta, .fa, .fna and .txt. File limit: 100 kB.
Template limits20–20,000 bases; A/C/G/T/N only. Case and whitespace are normalized. Other IUPAC ambiguity symbols are rejected.
PrimersTwo user-supplied sequences of 15–35 bases, A/C/G/T only. Sites must face inward without overlap. The search allows up to three mismatches per primer.
Product searchWithin the supplied sequence only; predicted products are limited to 2,000 bp. This is not a whole-genome specificity search.
Data handlingThe app reads the file locally, without uploading sequence contents. Imported DNA is unverified. Close or reload the page to clear the session; export JSON to retain a completed run.
Outside this importerMultiple FASTA records, whole genomes over the size limit, RNA, FASTQ reads, AB1 chromatograms, GenBank records, sequencing quality scores and instrument fluorescence files.

Public reference-sequence verification

The import workflow was checked using bases 1–400 of the NCBI RefSeq lambda genome, accession NC_001416.1. A local FASTA file was uploaded through the browser, and its sequence was retained in the completed JSON export. With an exact terminal primer pair used as a software fixture, the model predicted the full 400-bp product and generated a control-valid run.

The fixture primers are GGGCGGCGACCTCGCGGGTT (forward) and CCGCAGTTCTTCAACCTCCC (reverse), both written 5′→3′. They were chosen to check software geometry, not optimized or experimentally validated as an assay. Source: NCBI RefSeq NC_001416.1 ↗.

What the result means

The sequence can be real while the output remains simulated. Binding, copy growth, fluorescence, melt peaks and QC are computed from the model’s assumptions. A positive call is not evidence that a physical experiment will amplify successfully, and a simulated melt peak does not establish independent specificity.

Scientific scope
Single-plex educational model; no clinical validation, per-specimen internal amplification control, primer-dimer/hairpin chemistry or measured efficiency. Scientific specialist evaluation is pending. No physical DNA reading or instrument operation is performed.

Risk-analysis demonstration

Load Aster and Echo and complete a run. Then enable no-template-control contamination under Experiment conditions and repeat. The failed control invalidates every call. Positive-control failure can be tested separately; low-copy dropout and late or ambiguous signals are handled as inconclusive evidence.
