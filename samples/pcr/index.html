 LAB FIELD GUIDE

Your first amplification.

  1. Inspect a vial. Each icon represents a different synthetic dataset. Aster is the reference; Echo has fewer copies; Null has no matching target; Veil is inhibited.
  2. Load the instrument. Drag vials onto the cycler or a tray slot. Click the instrument or an empty slot to choose a DNA specimen. Adjust starting copies in the tray.
  3. Program the run. Annealing temperature, extension duration, cycles and replicates affect the generated data. Playback only changes animation speed.
  4. Run and investigate. Watch denaturation, annealing and extension. After the melt scan, inspect Cq, replicate agreement and control validity.

Try Aster and Echo together. Then repeat with a contaminated control or a higher annealing temperature. Controls determine whether sample calls are valid.

 DETERMINISTIC ENGINE / 0.2

What this lab models.

DNA and primers determine binding sites and product length. SantaLucia nearest-neighbour parameters estimate primer Tm; an empirical long-product formula estimates melt Tm. Salt is fixed at 50 mM and total primer strand concentration at 0.5 µM.

Copy number follows N(n) = N(n−1) × [1 + E(n)], with reagent saturation. Efficiency responds to primer mismatches, annealing temperature, extension time and inhibition. Poisson sampling adds low-copy variability; seeded Gaussian detector noise makes runs reproducible.

Analysis uses a linear baseline over cycles 3–12, a shared threshold of 10 × NTC baseline SD (minimum 10 RFU), interpolated sustained crossings, replicate QC and a melt check. Curve shape uses a signal/monotonicity heuristic. Cq values beyond the demo cutoff of 35 are inconclusive. Failed controls invalidate the run.

Limits: this is an educational single-plex model, not a validated instrument or chemical kinetics solver. Low-temperature off-target chemistry, dimers, hairpins, magnesium effects and internal controls are not modeled. Efficiency is not measured without a dilution series. Custom FASTA is unverified. Cooper provides optional, constrained run explanations through an external LLM service. Calls and QC remain deterministic. There is no authenticated production release gate.

References: Biopython thermodynamics · MIQE 2.0

 NEW SPECIMEN

Import a DNA sequence.

Single-record FASTA or DNA text, 20–20,000 bp (A/C/G/T/N). Supply both primers in 5′→3′ orientation. Reference or real sample-derived sequences can be simulated; no laboratory measurement is performed. DNA sequences and names stay in this browser; optional Cooper advice sends only anonymous run metrics. Imported sequences remain unverified.
