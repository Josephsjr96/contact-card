Data analysis & reporting

From raw records
to useful comparisons.

Data Explorer is an academic Python project that turns a small movie dataset into a cleaned report and an interactive desktop dashboard.

74input rows
72unique movies after cleaning
6dataset columns

Dataset scope
Movie titles come from 2026 release listings. Ratings, budgets and revenues are simulated practice values. This analysis demonstrates a workflow; it does not describe actual film performance.

The question

How can a messy dataset become a clear report? The application lets a reader compare genres, inspect rankings and understand the summary statistics behind the charts.

Preparing the data

  • Remove duplicate rows and convert numeric fields.
  • Fill missing numeric values with column medians.
  • Label missing genre values as unknown.
  • Keep data previews available so users can inspect the records behind the analysis.

What the dashboard shows

  • Genre comparisons based on average ratings.
  • Revenue rankings and total revenue for the practice dataset.
  • Mean, median and standard deviation of ratings.
  • Filters combining rating and revenue-versus-budget conditions.

Tools & contribution

Built with Python, Pandas, NumPy and PySide6, with a command-line report and a desktop interface. This project demonstrates data preparation, descriptive analysis and reporting rather than predictive modeling.
